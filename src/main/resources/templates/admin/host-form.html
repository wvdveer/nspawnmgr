Guacamole's RDP negotiation mode. Leave on ANY unless RDP fails to connect — some xrdp versions (e.g. Fedora's) reject ANY for reasons unrelated to credentials; RDP (classic security) is the known workaround. Applies immediately if RDP is already connected, no restart needed.

Where the session page shows buttons for admin-configured key sequences (see /admin/key-sequences) - key combinations a browser can never deliver as a real keypress, Ctrl+Alt+Delete being the classic example. NONE hides it.

When enabled, every "Copy to host" from this container/host's own session page writes the copied text (up to 250 characters) into the shared audit log (see /nspawnmgr/logs) - visible to every logged-in nspawnmgr user, not just this container's owner. Off by default since copied text routinely includes passwords.
