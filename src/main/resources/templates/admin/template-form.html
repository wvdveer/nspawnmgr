Preinstalled: the template's own image already has openssh installed and enabled - skips the redundant install/enable step when a container is created from it. Not capable: there's no way to install it via this template (e.g. no package manager).

A shell command with a single %s for the desktop session command (e.g. startxfce4), used to write the .vnc/xstartup script. Default is a bare exec, TigerVNC's own natural behavior - logging out ends the VNC session (TigerVNC 1.12+ kills Xvnc the instant the xstartup script's own process exits); the next connection attempt starts a fresh one automatically.

Matches the VNC server binary's own process name, anchored as "(^|/)<pattern> :0 " against a process's full command line (tolerating the absolute path it's normally invoked with) - used to find and kill a stale instance before starting a fresh one. Default X[a-z]*vnc matches both Xvnc and Xtigervnc (the actual binary name Debian's tigervnc-standalone-server execs).
