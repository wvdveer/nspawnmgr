Command

The command run as this pod's main process, like a Dockerfile CMD - left blank, the pod trusts whatever command its image already has built in. If that's a plain interactive shell (or anything else that doesn't keep running on its own), the pod will exit within moments of starting - or, if the image has no command at all, it'll fail to start entirely. Changing this only takes effect the next time the pod is recreated, which happens automatically on Save - only available while the pod is stopped, or in ERROR (e.g. it never managed to start at all - this is how you'd fix that).

Remote access

Checks the port is actually listening before connecting it to Guacamole. You'll be prompted for credentials each time you connect, since nspawnmgr doesn't generate or store an account for a pod.

SSH: not connected via nspawnmgr. SSH: connected (prompts for credentials).
RDP: not connected via nspawnmgr. RDP: connected (prompts for credentials).
VNC: not connected via nspawnmgr. VNC: connected (prompts for credentials).
