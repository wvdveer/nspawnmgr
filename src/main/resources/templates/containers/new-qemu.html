Some older guest OSes need a specific model to see any network at all - e.g. FreeDOS typically needs "pcnet".

USB tablet fixes mouse-cursor drift in VNC for GUI guests, but DOS-family OSes have no USB support and need PS/2.

No ISOs uploaded yet — see the Packages admin page. The VM can still be created with an empty disk and no boot media, but nothing useful will happen until an ISO is mounted from its own page.

The VM boots straight from its ISO (installer) until an OS is actually installed onto the disk and the ISO is ejected from the VM's own page — the same "boot device" switch stays available afterward, e.g. to run a repair disc later.

VNC console access is configured automatically (a Connect button appears once the VM is running). SSH and RDP aren't set up automatically — enable them from the VM's own page once a guest OS with those services is installed and running.
